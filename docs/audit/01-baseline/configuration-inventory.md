## 4. Configuration Risks & Observations

1. **Package Manager Divergence:** `bun.lock` is present in the repository root, but `Dockerfile` specifies `npm ci`, and development scripts rely on `tsx` via `npm`.
2. **HMR Disabling Logic:** `vite.config.ts` explicitly disables file watching and HMR when `DISABLE_HMR=true`. This is an AI Studio optimization to prevent process churn during bulk edits.
3. **Dual Execution Paths:** The server can be run via TypeScript interpreter (`tsx server.ts`) in development or compiled CommonJS (`node dist/server.cjs`) in production.
